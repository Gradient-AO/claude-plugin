# Manager-comparison analysis examples

Set `meta.data_basis` to `gradient_governed` or `mixed`. The source table columns are exactly `Tag`, `Evidence`, `Basis`, `Tool / view`, `Key parameters`, `As of`, `Data scope`, `Validation`, `Digest`.

## Risk and return

**Strong example (TEST):** Observation: Manager A returned 7.4% versus Manager B at 6.8% through June 2026 [S3]. Why it matters: Manager A led on the governed return measure. Uncertainty: The managers have different inception dates. What would change the view: A common-window result reversing the 0.6-point lead.

## Relative performance and capture

**Strong example (TEST):** Observation: Manager A led its assigned benchmark by 0.6 percentage points [S4]. Why it matters: Relative evidence supports the observed return lead. Uncertainty: The governed response lacks capture statistics. What would change the view: Governed downside capture above 110% for Manager A.

## Correlation and robustness

**Strong example (TEST):** Observation: Both managers remained positive in three returned windows [S5]. Why it matters: Neither result depends on one reported period. Uncertainty: The governed response lacks correlation evidence. What would change the view: A governed common-window correlation above 0.80.
