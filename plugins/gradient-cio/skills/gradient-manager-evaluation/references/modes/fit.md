# Fit mode

Use only for one user-named prospective manager after the selected return
series is available.

Required sections:

1. Evaluation summary
2. Candidate and portfolio basis
3. Correlation and diversification
4. Expected statistics
5. Simulation versus the current portfolio
6. Stress and limitations
7. Conditions and next steps
8. Appendix — Sources and methods

Compare the candidate with the current portfolio using governed returned
correlation, expected statistics, and simulation evidence. Label expected
returns under the shared provenance contract. Never infer operational quality,
external-population standing or a hire recommendation.
