## Summary

**Strong (TEST)**
> **Observation:** The portfolio returned 5.8% over one year, 1.4 points below policy, with two rows on Watch [S2]. **Why it matters:** Underperformance and policy headroom drive monitoring. **Uncertainty:** Look-through coverage is limited to 86% of NAV. **What would change the view:** A quarter-end report showing excess return above zero and no Watch rows would improve the summary.

**Weak contrast:** “Results identify monitoring priorities [S2].” It provides no specific evidence, portfolio implication, coverage limitation, or measurable quarter-end trigger.
