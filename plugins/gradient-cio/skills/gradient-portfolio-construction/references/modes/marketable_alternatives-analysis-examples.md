## Target Strategy and Manager Structure

**Strong (TEST)**
> **Observation:** Equity long-short is 44% of the sleeve versus a 30% target, while macro strategies are 9% against an 18% target [S3]. **Why it matters:** The target mix reduces one equity-sensitive dependency. **Uncertainty:** Classification coverage is unavailable for two managers. **What would change the view:** A classification refresh showing equity long-short below 35% would narrow the structural gap.

**Weak contrast:** “The target manager mix is more diversified [S3].” It has no strategy gaps, return-source implication, classification limitation, or measurable refresh condition.

## Forward Return and Risk

**Strong (TEST)**
> **Observation:** The target sleeve models at 7.2% return and 8.8% volatility versus 6.8% and 9.6% currently [S7]. **Why it matters:** The target improves modeled efficiency without increasing the sleeve allocation. **Uncertainty:** The model assumes stable cross-strategy correlations. **What would change the view:** A refreshed result with target volatility above 10% would remove the apparent improvement.
